How-to guides

Directions for a specific goal.

  • Inject Spring beans Inject beans from a Spring application context into pages, components, behaviors and other objects with @SpringBean.
  • Inject CDI beans Configure wicket-cdi so pages, components, behaviors and the session get CDI beans with @Inject, and choose beans that survive serialization.
  • Inject EJBs Inject session beans, JNDI resources and persistence units into Wicket components with @EJB, @Resource and @PersistenceUnit, through WicketStuff's javaee-inject module.
  • Inject with JSR-330 annotations Use the standard @Inject and @Named annotations instead of @SpringBean, with the Spring, Guice and CDI integrations.
  • Run on Apache Karaf Install Wicket in Apache Karaf or another OSGi container with the Karaf feature that every Wicket release publishes.
  • Inspect and change settings with JMX Add wicket-jmx to see a running application's settings and session counts in JConsole, clear the markup cache, and change some settings without a restart.
  • Measure with Wicket metrics Count requests and time component creation, rendering and model loading with the experimental wicket-metrics module, AspectJ and Dropwizard Metrics.
