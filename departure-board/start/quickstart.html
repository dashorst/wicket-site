Quick start

Generate a Wicket project with Maven in a minute, run it, and open it in your browser.

Run this in a terminal

mvn archetype:generate \
  -DarchetypeGroupId=org.apache.wicket \
  -DarchetypeArtifactId=wicket-archetype-quickstart \
  -DarchetypeVersion=10.12.0 \
  -DgroupId=com.mycompany \
  -DartifactId=myproject \
  -DinteractiveMode=false

Needs Maven and Java 17 or newer. Wicket 10 is supported until 14.0.0, Jul 2027.

Five steps to a running application

  1. Fill in the Maven coordinates of your project and pick a Wicket version. The group ID also becomes the Java package.
  2. Copy the command and run it in a terminal. Maven creates a folder named after the artifact ID.
  3. Open the project in your IDE. Every current Java IDE imports Maven projects directly.
  4. Run the main method of the Start class in src/test/java.
  5. Open http://localhost:8080.

Create a project explains what the generated project contains and how to adjust it, and Build your first application takes it from there. The same project is what the users list asks for when you report a bug: a small application that shows the problem.
