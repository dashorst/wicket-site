Build web applications from Java components and plain HTML

Apache Wicket is a component-oriented Java web framework, open source since 2004 and a project of the Apache Software Foundation since 2007. Every component keeps its behaviour and state in Java and its markup in plain HTML, so there is no JavaScript build chain to maintain.

Why Wicket

  1. A page is a Java class and an HTML file

    Use what you know about Java and your favourite HTML editor. Behaviour lives in Java, markup stays plain HTML, and no JavaScript build is needed.

    • The wicket:id joins each tag to the Java component with the same id. The HTML stays plain HTML that any editor opens.
    • A click runs onClick() on the server, and Wicket renders the page again.
    • The field clicks keeps its value between requests, because Wicket keeps the page object for you.
    • A part you reuse on many pages is a Panel: again a Java class and an HTML file. Components and markup shows how.

    See the examples running

    HomePage.java

    HomePage.html

  2. Components for complex pages

    Pages and components are real Java objects with encapsulation, inheritance and events. Build a panel once and use it on every page, and bundle a component with its stylesheets, JavaScript and other resources into one reusable package.

    AddressPanel.java

  3. Ajax without writing JavaScript

    Update selected parts of a page from Java, without a single line of JavaScript. An Ajax request re-renders only the components you add to it, and Wicket comes with a large set of ready-made Ajax components.

    CounterPage.java

  4. Secure by default

    URLs do not expose sensitive information and component paths are session-relative. Wicket supports a Content Security Policy without unsafe-inline: it adds a nonce to every header contribution itself, and you add only the sources your application needs. Configure the Content Security Policy shows how.

    MyApplication.java

  5. Tested without a browser

    WicketTester renders your pages and components in a unit test, without a browser or a container, and checks their markup, attributes and contents. It clicks links and submits forms as a visitor would.

    HomePageTest.java

Built by the people who use it

Apache Wicket is developed in the open by volunteers. Answer a question on the users list, report a bug with a quickstart, improve the documentation, or send a pull request to apache/wicket: a committer reviews it, and it goes out with the next release of its line.
