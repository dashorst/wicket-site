Start here

Five lessons that build one application, from an empty project to a tested page with Ajax. To get a running project in a minute first, use the quick start.

  1. Build your first application Generate a project from the quickstart, run it, and build a home page with a label, a click counter and a link to a second page.
  2. Give every page the same layout Move the header, navigation and footer of your application into a base page and two panels, so every page shares one layout.
  3. Build a form that saves data Add a guestbook page with a form that validates its input, saves entries and lists them, and shows errors and a confirmation.
  4. Update a page with Ajax Make the click counter and the guestbook form update only the parts of the page that change, open the form without a reload, and refresh the guestbook every ten seconds.
  5. Test a page with WicketTester Write JUnit tests that render your pages, click links, submit the guestbook form and check Ajax updates, without a browser or a server.

API documentation

Maven downloads the sources with every Wicket release, so your IDE shows the Javadoc when you hover over a class. To link to it, use the Javadoc online: Wicket 10 (LTS). Older lines link to theirs from their release line page.

Upgrading

Every major release has a migration guide on the wiki with the API changes and what to do about them, linked from its release line page. The upgrade paths show the route from a line out of service to one that is supported.

Older versions

The documentation covers the release lines in service. Pages marked with a version, like Wicket 11+, need that version or later. Every line also has its reference guide as one document; for lines out of service it is their only guide: Wicket 9, Wicket 8, Wicket 7.
