How-to guides

Directions for a specific goal.

  • Test pages and components Render pages and single components in a unit test, click links, fire Ajax events and check what they render, with WicketTester and JUnit.
  • Test forms Fill in fields, pick options, upload files and submit a form in a unit test with FormTester, then check the feedback messages and the model.
  • Test markup Find tags in the rendered output with TagTester and check their attributes and content, render a component to a string, or compare a page with an expected file.
  • Test with Spring Test pages that use @SpringBean with WicketTester, either with mock beans in an ApplicationContextMock or against a real Spring test context.
