Getting started

  • Build your first application Generate a project from the quickstart, run it, and build a home page with a label, a click counter and a link to a second page.
  • Give every page the same layout Move the header, navigation and footer of your application into a base page and two panels, so every page shares one layout.
  • Build a form that saves data Add a guestbook page with a form that validates its input, saves entries and lists them, and shows errors and a confirmation.
  • Update a page with Ajax Make the click counter and the guestbook form update only the parts of the page that change, open the form without a reload, and refresh the guestbook every ten seconds.
  • Test a page with WicketTester Write JUnit tests that render your pages, click links, submit the guestbook form and check Ajax updates, without a browser or a server.
