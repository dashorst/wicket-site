Several books have been written about Apache Wicket, covering beginner introductions
through advanced development techniques.

---

## Wicket in Action

*By Martijn Dashorst and Eelco Hillenius — Manning Publications, 2008*

The authoritative, comprehensive guide for Java developers building Wicket-based web
applications. This book starts with an introduction to Wicket's structure and components,
and moves quickly into examples of Wicket at work. Written by two of the project's earliest
experts, it covers both the "how-to" and the "why" of Wicket, including integration with
Spring and Hibernate, and building rich Ajax-driven features.

[Manning Publications &rarr;](https://www.manning.com/books/wicket-in-action){:target="_blank" rel="noopener"}

---

## Apache Wicket Cookbook

*By Igor Vaynberg — Packt Publishing, March 2011*

A hands-on practical guide covering a wide variety of Wicket topics and use cases. This
cookbook goes beyond the basics to show how to leverage Wicket's advanced features to create
simpler and more maintainable solutions. Topics include form processing, Ajax support,
integration with JavaScript libraries, security, and working with other frameworks.
ISBN: 978-1-84951-160-5.

[Packt Publishing &rarr;](https://www.packtpub.com/product/apache-wicket-cookbook/9781849511605){:target="_blank" rel="noopener"}

---

## Instant Apache Wicket 6

*By Jo&atilde;o S&aacute;vio Ceregatti Longo and Felipe Fedel Pinto — Packt Publishing, August 2013*

A short, focused starter guide for developers who want to learn the basics of Apache Wicket 6
quickly. Covers setting up the environment, building a Hello World application, core concepts
(lifecycle, models, markup, behaviours), and using Maven with Eclipse. Ideal for those with
some Java experience who want to get up and running fast. ISBN: 978-1-78328-001-8.

[Packt Publishing &rarr;](https://www.packtpub.com/web-development/instant-apache-wicket-6-instant){:target="_blank" rel="noopener"}

---

## Enjoying Web Development with Wicket

*By Kent Tong — A self-published book covering Wicket fundamentals*

A beginner-friendly introduction to Wicket that walks through building web applications
step by step. Covers forms, validation, models, and common Wicket patterns with
practical examples throughout.
