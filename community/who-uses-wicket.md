Wicket has been production-proven for over twenty years and powers applications in many
industries — from large financial institutions to nimble startups. This page is a
community-maintained showcase of projects that use Apache Wicket.

## Showcase Being Rebuilt

We are in the process of rebuilding the project showcase for the new site. The showcase
will be driven by community submissions stored as Markdown files in the repository.

If you want to submit your project to the showcase before it goes live, please open a
pull request on the
[wicket-site repository](https://github.com/apache/wicket-site){:target="_blank" rel="noopener"}
and add a Markdown file describing your project to `src/content/showcase/`.

## How to Submit Your Project

1. Fork the [wicket-site](https://github.com/apache/wicket-site){:target="_blank" rel="noopener"} repository on GitHub.
2. Add a new Markdown file in `src/content/showcase/` with details about your project.
   Use the following frontmatter fields:
   - `title` — Name of your project or company
   - `url` — Link to the project website
   - `description` — A short description of the project and how it uses Wicket
3. Open a pull request and the Wicket team will review and merge it.
