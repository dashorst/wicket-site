# Groundwork for alternative directions (homepage, Persuade)

Mechanism: Wicket builds web interfaces as a tree of stateful Java components, each bound to plain HTML by a `wicket:id` attribute: markup and code side by side, no template language, no JavaScript build chain.
Audience scene: Java developers and architects at a desk in an enterprise, government or university team, maintaining long-lived applications; evaluators comparing frameworks; Apache community members reading release mail.
Cultural home: the Apache Software Foundation and the Java ecosystem: mailing lists, Maven Central, Javadoc, the user guide, twenty years of open source.
First surface must prove: Wicket is alive (new release model, 11.0 out), what it is (components in plain Java + HTML), and that existing users keep their footing (LTS, upgrade paths).

The rut: the developer-framework landing page (dark hero with gradient, a floating code window, three feature cards, "Get started" button) and its predictable opposite (a bare white docs page). The governing metaphors already spent: the departure board (built, the incumbent anti-reference) and the name's literal reading, cricket (at most one candidate).

Seven candidates, by resonance:
1. Engineering drawing sheet: ISO title block, orthographic views, part callouts, revision table. A component is a part drawn in two views (markup and Java); releases are revisions. (graphic tradition: technical drawing)
2. Assembly instructions: IKEA / LEGO Technic manuals, numbered wordless steps, exploded views, parts inventory. Composing a page from components is assembly. (artifact: printed manual)
3. Swiss International Typographic Style: Müller-Brockmann grid systems, objective typography, a strict modular grid as the identity. Components on a grid. (graphic tradition: design school)
4. IETF RFC / plain-text standards document: fixed headers, numbered sections, ASCII figures, the "plain HTML" ethos of the web's own documents. (documentation standard)
5. Element and specimen charts: the periodic table, type specimen sheets; a catalogue of reusable components with properties. (data graphic)
6. Library card catalogue: index cards, accession numbers, cross-references; twenty years of releases and announcements as a catalogue. (place/ritual)
7. Cricket scoreboard: hand-turned numerals on a pavilion board, the name's literal reading. (object; the one name candidate)

Families covered: technical graphics (1), printed manuals (2), design schools (3), documentation standards (4), data graphics (5), places and rituals (6, 7).
